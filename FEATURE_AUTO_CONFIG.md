# ✨ 新功能：自动配置生成

> [!WARNING]
> 这是已归档的 v0.2/v0.3 设计记录。v0.4 不保存服务商账号密码；不要执行本文步骤，请以当前 [README.md](README.md) 为准。

## 概述

WireGuard TUI 现在支持**配置文件自动生成**！首次运行时，应用会自动创建配置模板，你只需要编辑凭证即可开始使用。

## 🎯 功能亮点

### 1. 零手动配置
- ✅ 运行应用即可自动生成配置
- ✅ 无需手动创建目录或文件
- ✅ 包含完整的注释说明

### 2. 智能检测
- ✅ 自动检测凭证是否为模板默认值
- ✅ 在界面显示配置状态
- ✅ 提示用户更新凭证

### 3. 用户友好
- ✅ 显示配置文件完整路径
- ✅ 提供逐步配置指导
- ✅ 彩色状态提示

### 配置文件内容

自动生成的 `~/.config/wireguard-tui/config.toml`:

```toml
# WireGuard TUI Configuration File
#
# This file is automatically generated on first run.
# Please update with your StrongVPN credentials.
#
# Get your credentials from:
# 1. Login to https://strongtech.org/account/
# 2. Click "Account Setup Instructions"
# 3. Look for "VPN Account Information"
# 4. Username starts with 'a'
#
# Note: These are your VPN credentials (AIO Username/Password),
# NOT your website login email/password!

# Your StrongVPN username (starts with 'a')
username = "your-vpn-username"

# Your StrongVPN password
password = "your-vpn-password"

# Automatically download configs on first run
auto_download = true

# Last connected server (managed automatically)
# last_server = "server-name"
```

### 编辑配置

```bash
nano ~/.config/wireguard-tui/config.toml
```

**只需更新两行：**
```toml
username = "your-actual-username"  # 改这里
password = "your-actual-password"  # 改这里
```

## 🔍 智能检测逻辑

应用检测以下情况来判断凭证是否已配置：

```rust
// 未配置的条件（任一为真）：
- username 为空
- username == "your-vpn-username" (模板值)
- password 为空
- password == "your-vpn-password" (模板值)
```

#### config.rs
```rust

fn create_config_template(&self) -> Result<()>
pub fn get_config_path_str(&self) -> String

// 在 new() 中调用
pub fn new() -> Result<Self> {
    // ... 创建目录 ...
    
    let manager = Self { ... };
    
    // 自动生成配置
    manager.ensure_config_exists()?;
    
    Ok(manager)
}
```

#### app.rs
```rust
// 在启动时检测凭证
pub async fn new() -> Result<Self> {
    // ... 加载配置 ...
    
    // 检测凭证是否已配置
    let credentials_configured = !config.username.is_empty()
        && config.username != "your-vpn-username"
        && !config.password.is_empty()
        && config.password != "your-vpn-password";
    
    // 如果未配置，显示提示
    let initial_message = if !credentials_configured {
        let config_path = config_manager.get_config_path_str();
        Message::Info(format!("⚠️ Please configure credentials in: {}", config_path))
    } else {
        Message::None
    };
    
    // ...
}
```
